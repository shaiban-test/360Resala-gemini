# خطة نقل ونشر منصة ChatAndCart على سيرفر Coolify وبيئة الإنتاج

خطة تشغيلية لنقل المنصة بالكامل من مستودع GitHub إلى سيرفر **Coolify** الخاص بك (`coolify.free-temp.eu.org`)، وربطها بدومين تجريبي (Staging Domain)، وإكمال البناء والاختبار الميداني الحي.

---

## 1. التجهيزات التي تمت في المشروع (Ready in Codebase)

1. **إعداد ملف `Dockerfile` مخصص للإنتاج**:
   - بناء متعدد المراحل (Multi-stage build) على `node:22-alpine` لخفة الحجم وسرعة التشغيل.
   - تشغيل خادم Express مع الـ API وخدمة ملفات الواجهة مبنية وجاهزة على المنفذ `3000`.
2. **إعداد ملف `.dockerignore`**:
   - لتسريع عملية الرفع والبناء وتجنب نقل المجلدات المؤقتة.
3. **مستودع Git محلي جاهز ومحدث**:
   - يحتوي على كافة التعديلات الأخيرة، الصفحة الرئيسية، لوحة الأدمن، ومعالج الإعداد.

---

## 2. خطوات النشر على سيرفر Coolify خطوة بخطوة

### الخطوة 1: إتمام المزامنة في Google AI Studio
- في النافذة الظاهرة في صورتك الأولى (تبويب **GitHub sync**):
  - اضغط على زر **`Create new repository`**.
  - اكتب اسم المستودع: **`Chatapp`** (سيكون الرابط: `https://github.com/shaiban-test/Chatapp`).
  - اضغط تأكيد؛ سيتم رفع جميع الملفات متضمنة `Dockerfile` فوراً.

### الخطوة 2: إنشاء التطبيق في لوحة Coolify
- ادخل إلى لوحة السيرفر الخاص بك: [https://coolify.free-temp.eu.org](https://coolify.free-temp.eu.org)
- من القائمة الجانبية:
  1. اضغط على **Projects** > اختر المشروع (أو أنشئ مشروعاً جديداً باسم `ChatAndCart`).
  2. اضغط على **+ New Resource**.
  3. اختر **Public Repository** (أو **Private Repository / GitHub App** إذا كان المستودع خاصاً).
  4. ضع رابط المستودع:
     ```
     https://github.com/shaiban-test/Chatapp
     ```
  5. الفرع (Branch): `main`.

### الخطوة 3: ضبط إعدادات البناء في Coolify
داخل صفحة التطبيق في Coolify، اضبط الإعدادات التالية:
1. **Build Pack**: اختر **`Dockerfile`** (سيكتشف Coolify ملف `Dockerfile` تلقائياً).
2. **Ports Exposes**: اكتب المنفذ `3000`.
3. **Domains (الدومين التجريبي)**:
   - ضع دومينك التجريبي، على سبيل المثال:
     ```
     https://chatapp.free-temp.eu.org
     ```
   - سيقوم Coolify عبر Traefik بإنشاء شهادة أمان SSL (HTTPS) تلقائية ومجانية عبر Let's Encrypt!

### الخطوة 4: إضافة المتغيرات البيئية (Environment Variables)
في قسم **Environment Variables** داخل التطبيق في Coolify، أضف المتغيرات التالية:
* `NODE_ENV` = `production`
* `PORT` = `3000`
* `GEMINI_API_KEY` = `مفتاح Gemini الخاص بك لتفعيل الردود الذكية الفورية`

### الخطوة 5: الضغط على Deploy
- اضغط على زر **`Deploy`** في أعلى لوحة Coolify.
- سيقوم السيرفر بسحب الكود، بناء الحاوية، وتفعيل الرابط في غضون 60 إلى 90 ثانية!

## 3. خطة الاختبار الميداني في البيئة الحقيقية (Real Environment Testing)

بمجرد اكتمال النشر على الدومين التجريبي:
1. **فحص الصفحة الرئيسية والروابط**:
   - الدخول إلى `https://chatapp.free-temp.eu.org` والتحقق من سرعة التحميل وتجاوب الواجهة على الموبايل والكمبيوتر.
2. **فحص لوحة الأدمن المحمية**:
   - زيارة `https://chatapp.free-temp.eu.org/admin`
   - تسجيل الدخول بالحساب: `admin` / `admin123456`
   - فحص إدخال بيانات Meta Tech Provider وتجربة فحص الاتصال الحي.
3. **فحص معالج إعداد الموظف الذكي (Onboarding)**:
   - تجربة سيناريو إنشاء تاجر جديد، تحديد اللهجة، إضافة خدمة/منتج، وتجربة مسح كود QR Code برقم حقيقي.
4. **فحص شات الموظف وسلة التسوق**:
   - محادثة الموظف الذكي بالعامية الخليجية/المصرية، وإضافة المنتجات للسلة، وإتمام عملية شراء تجريبية والتأكد من ظهورها فورياً في لوحة تحكم التاجر.
5. **ربط الويب هوك مع Meta WhatsApp**:
   - إدخال رابط الويب هوك الحقيقي `https://chatapp.free-temp.eu.org/api/webhooks/whatsapp` في لوحة مطوري فيسبوك (Meta for Developers) واختبار استقبال وإرسال رسائل واتساب الحقيقية.
